# מפרט עיצוב — עמוד צוות המאמנים

## מטרה

עדכון עמוד "מאמנים" (כיום `locations.html`) כך שיציג את צוות המאמנים באופן אופקי — תמונה בצד ימין וטקסט בצד שמאל — עם שישה מקומות ריקים שיימלאו בתוכן מאוחר יותר.

## עקרונות עיצוב

- **סקאלאביליות:** העמוד צריך להתרחב בקלות כשיתווספו מאמנים נוספים.
- **עקביות:** כל כרטיס מאמן עוקב אחרי אותו תבנית.
- **קריאות:** רשימה אנכית אחידה עם הפרדה ויזואלית בין פריטים.
- **מובייל ראשון:** בנייד הכרטיסים יתערמו לכדי תמונה מעל טקסט.

## מבנה העמוד

מלמעלה למטה:

1. **Header** — לוגו + ניווט ראשי (קיים).
2. **Page header** — כותרת: "צוות המאמנים".
3. **רשימת מאמנים** — 6 כרטיסים אופקיים זהים בתבנית.
4. **Footer** — משותף (קיים).

## כותרת העמוד

- כותרת ראשית: **צוות המאמנים**
- תיאור משנה (lede): טקסט קצר שמסביר שמדובר בצוות המאמנים של העמותה — placeholder עד לקבלת תוכן סופי.

## תבנית כרטיס מאמן

כל כרטיס כולל את השדות הבאים, לפי סדר הופעה:

| שדה | תיאור |
|-----|-------|
| תמונה | מקום ריק עם רקע צבעוני ואותיות ראשונות של שם המאמן (placeholder) |
| שם | שם המאמן |
| ביו | טקסט קצר על המאמן |
| מיקום/מועדון | שם המועדון / העיר כחלק מהביו או כשורה נפרדת |
| קשר | כפתור/קישור לוואטסאפ |

### מבנה ויזואלי (דסקטופ)

```
┌─────────────────────────────────────────────────────────────┐
│  [שם]                              [                        ] │
│  [ביו]                              [      תמונת מאמן      ] │
│  [מיקום]                            [        (עיגול)        ] │
│  [כפתור וואטסאפ]                   [                        ] │
└─────────────────────────────────────────────────────────────┘
```

- התמונה בצד ימין, הטקסט בצד שמאל (מתאים ל-RTL).
- כרטיס באורך מלא של הקונטיינר.
- מרווח פנימי גדול דיו כדי שהכרטיס לא ייראה צפוף.
- רוחב מקסימלי של הקונטיינר: ~900px כדי שהשורות לא יתמתחו מדי.

### מבנה ויזואלי (מובייל)

```
┌─────────────────────────────┐
│      [   תמונת מאמן   ]      │
│           (עיגול)           │
├─────────────────────────────┤
│          [שם]               │
│          [ביו]              │
│          [מיקום]            │
│      [כפתור וואטסאפ]        │
└─────────────────────────────┘
```

- התמונה מעל הטקסט, ממורכזת.
- הטקסט מיושר למרכז או לימין — לפי מה שנראה נקי יותר בבדיקה.

## תמונות placeholder

- עיגול צבעוני עם אותיות ראשונות של שם המאמן (כמו ה-placeholder הקיים).
- צבע הרקע נשמר עקבי — למשל גוון אפור-כחלחל או גוון המותג האדום בהירות נמוכה.
- גודל: ~120px בדסקטופ, ~100px במובייל.

## כפתור וואטסאפ

- כפתור קטן עם אייקון וואטסאפ + טקסט "שלח הודעה".
- מקשר ל-`https://wa.me/972XXXXXXXXX` עם הודעה מוכנה מראש.
- במובייל הכפתור באורך מלא או רחב דיו ללחיצה נוחה.

## הפרדה בין כרטיסים

- קו דק או רווח גדול בין כל מאמן.
- אופציה: רקע בהיר מאוד (אפור-כמעט-לבן) לכרטיסים זוגיים — עוזר לעין לעקוב ברשימה ארוכה.

## התנהגות רספונסיבית

| מסך | פריסה |
|-----|-------|
| דסקטופ (>768px) | תמונה ימין, טקסט שמאל, כרטיס אחד בשורה |
| טאבלט | אותו דבר, רוחב קונטיינר מתכווץ |
| מובייל (<768px) | תמונה מעל, טקסט מתחת, כפתור מלא |

## Placeholders לתוכן

לכל אחד מששת המאמנים יהיו ה-placeholders הבאים:

- **שם:** "מאמן 1", "מאמן 2" וכו' או ריק
- **ביו:** "פרטים על המאמן יתווספו כאן."
- **מיקום:** "מועדון ___ / עיר ___"
- **טלפון:** placeholder — ללא קישור פעיל עד לקבלת מספר אמיתי
- **תמונה:** עיגול צבעוני עם אותיות ראשוניות מתאימות

## מחוץ לטווח

- אין אנימציות מורכבות — רק hover פשוט על הכפתור.
- אין סינון או חיפוש מאמנים בשלב זה.
- אין עמודי פרופיל נפרדים לכל מאמן.
- אין שינוי בניווט או ב-footer — רק תוכן העמוד משתנה.

## קריטריוני הצלחה

- העמוד מציג 6 כרטיסי מאמנים בתבנית אחידה.
- בדסקטופ: תמונה ימין, טקסט שמאל.
- במובייל: תמונה מעל, טקסט מתחת.
- כל כרטיס כולל שם, ביו, מיקום, וכפתור וואטסאפ placeholder.
- התמונות הן placeholders צבעוניים עם אותיות ראשוניות.
- העמוד נשאר קריא ונקי גם כשנוסיפו מאמנים נוספים בעתיד.
