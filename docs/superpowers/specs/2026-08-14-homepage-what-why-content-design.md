# עיצוב: עדכון תוכן #what ו-#why בדף הבית

## מטרה
להחליף את טקסטי ה-placeholder בקלפים של המקטעים `#what` ו-`#why` בדף הבית בטקסטים אמיתיים שסופקו, ולהוסיף משפטי סיום מודגשים ומרכוזים מתחת לכל אחד מהמקטעים.

## שינויים מתוכננים

### 1. `src/pages/index.html`

#### מקטע `#what` — "מה זה שאי הון?"

עדכון כותרות ותוכן בקלפים:

| קלף נוכחי          | כותרת חדשה                     |
|--------------------|--------------------------------|
| קראטה              | קראטה                          |
| ג'ודו              | ג'ודו                          |
| אגרוף              | אגרוף                          |
| הגנה עצמית         | שיטת הגנה עצמית ייחודית        |

תוכן כל קלף יוחלף בטקסט המתאים שהועבר.

הוספת משפט סיום מתחת לרשת הקלפים:

> שילוב כל המרכיבים יוצר שיטה הגדולה מסך חלקיה

#### מקטע `#why` — "למה שאי הון?"

עדכון כותרות ותוכן בקלפים:

| קלף נוכחי                | כותרת חדשה              |
|--------------------------|-------------------------|
| כושר גופני               | כושר וחיזוק הגוף        |
| חיזוק ביטחון עצמי        | ביטחון עצמי             |
| הגנה עצמית               | הגנה עצמית              |
| קהילה                    | קהילתיות                |

תוכן כל קלף יוחלף בטקסט המתאים שהועבר.

הוספת משפט סיום מתחת לרשת הקלפים:

> בשאי-הון אנו מאמינים שאומנות לחימה היא דרך לחיים. לצד היכולות הפיזיות, המתאמנים מפתחים משמעת, אחריות, התמדה, כבוד לאחר ויכולת להתמודד עם הצלחות וכישלונות. ערכים אלו מלווים אותם בבית, בבית הספר, בעבודה ובכל תחומי החיים.

### 2. `src/pages/styles.css`

הוספת מחלקת CSS חדשה — `.section-closing` — למשפטי הסיום:

- טקסט מרכוזי (`text-align: center`).
- גופן גדול יותר מהטקסט הרגיל בקלפים (למשל `1.25rem` עד `1.5rem`).
- מרווח עליון ניכר (`margin-top`) כדי להפריד מרשת הקלפים.
- צבע טקסט תואם לפלטה הנוכחית (אפור כהה/שחור על רקע בהיר).
- שורת גובה נוחה לקריאה.

## מה לא משתנה

- מבנה ה-HTML של המקטעים נשמר.
- התמונות ברקע הקלפים נשמרות.
- התנהגות הקלפים (הרחבה בלחיצה/הover, נגישות מקלדת) נשמרת — ללא שינויי JS.
- הניווט, הפוטר ושאר עמודי האתר נשארים ללא שינוי.

## קבצים שייערכו

- `src/pages/index.html`
- `src/pages/styles.css`
